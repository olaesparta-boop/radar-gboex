      Radar GBOEX · Grêmio Beneficente, entidade de previdência e seguro de pessoas desde 1913 · coleta automática diária pelo GitHub Actions · botão Atualizar dispara uma coleta na hora

      Coleta remota

      O painel é um site estático: ele sozinho não consegue vasculhar as fontes. Quem coleta é o GitHub Actions. Com um token seu salvo aqui, o botão Atualizar dispara uma coleta nova e recarrega o painel quando ela terminar (leva de 2 a 6 minutos).

      1. Abra github.com/settings/personal-access-tokens/new (token fine-grained).
      2. Em Repository access, escolha Only select repositories → radar-gboex.
      3. Em Permissions → Repository permissions, marque Actions: Read and write.
      4. Gere o token, copie e cole abaixo.

      O token fica salvo só neste navegador (localStorage), nunca vai para o repositório. Ele permite disparar e ler execuções deste repositório — se vazar, revogue em Settings → Developer settings.
